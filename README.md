# MeTube Pocket

Легковесный нативный Android-клиент для self-hosted сервера [MeTube](https://github.com/alexta69/metube) (yt-dlp frontend).

## Особенности
*   **Нативный интерфейс (Jetpack Compose)**: Никаких WebView, только быстрый и плавный UI.
*   **Android Share Target**: Делитесь видео прямо из приложения YouTube (Кнопка "Поделиться" -> "MeTube Pocket"). Ссылка подхватится автоматически.
*   **Выбор параметров**: Настройка формата, качества и кодека перед отправкой.
*   **Опрос статусов (Polling)**: Автоматическое обновление списка загрузок без WebSocket, стабильная работа.
*   **Темы оформления**: Поддержка Системной, Светлой, Тёмной тем, а также кастомных ретро-тем Ретро98 (стиль Windows 98) и Ретро-XP (стиль Windows XP).

## Как собрать проект
Проект настроен для автоматической сборки через GitHub Actions. 
1. Сделайте форк или загрузите код в свой репозиторий GitHub.
2. Перейдите во вкладку **Actions**.
3. Нажмите **Run workflow** -> **Android Build**.
4. После завершения сборки скачайте готовый `app-debug.apk` из раздела Artifacts.

## Требования
*   Android 7.0+ (API 24+)
*   Запущенный сервер MeTube (работает по HTTP/HTTPS)

## Настройка
При первом запуске перейдите на вкладку "Настройки" и укажите IP и порт вашего сервера MeTube, например: `http://192.168.1.100:8081`. Обязательно проверьте соединение соответствующей кнопкой!
